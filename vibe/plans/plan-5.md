# plan-5: Сервер и контракт ИИ-мастера

Статус: запланирован.
Родитель: [roadmap-1](../roadmap/roadmap-1.md).

## Цель

Подготовить защищённое от утечки ключа соединение приложения с мастером.

## Зависимости

[plan-4](plan-4.md) завершён.

## Перед началом

Прочитать roadmap-1, этот план и инструкции репозитория. Проверить текущий код и Git status; сохранить чужие изменения. Использовать существующий checkout: отдельный worktree без запроса пользователя не создавать. Уточнять только вопросы, блокирующие работу. Выбор библиотек и версий фиксировать по фактически доступным инструментам.

## Шаги реализации

1. Выбрать простой серверный стек и одного ИИ-провайдера; зафиксировать обоснование, версии и lockfile. Подготовить адаптер для тестового провайдера.
2. Описать версионированный контракт: генерация завязки, действие игрока и передача результата броска. Ответ содержит текст и структурированные предложения операций, а не произвольную команду выполнения.
3. Хранить ключ только на сервере через переменные окружения. Добавить пример конфигурации без значений секретов, исключить секреты и содержание личных диалогов из обычных логов.
4. Реализовать валидацию входов/выходов, таймауты, ограничение размера запросов, обработку ошибок и идентификаторы запросов для защиты от повторной обработки.
5. Для локального прототипа ограничить доступ локальной разработкой. До любого публичного доступа предусмотреть авторизацию, ограничения частоты и расходов; не открывать публичный платный endpoint без защиты.
6. Добавить health-check, команды запуска и интеграционные тесты с тестовым провайдером. Проверить реальный провайдер только при наличии безопасно настроенного ключа и зафиксировать результат отдельно.

## Критерии готовности и проверки

Health-check и серверные интеграционные тесты проходят; неверный ответ провайдера отклоняется, повторный запрос не создаёт повторную операцию. Ключ отсутствует в iOS-проекте и Git.

Запускать содержательные проверки для изменённого поведения. Указать команды, среду и фактический результат; нулевое число тестов и проверка исходников не заменяют сборку и запуск. Если нет Mac, устройства или ключа, выполнить независимую часть и явно указать блокер: план целиком не закрывать.

Публичный production-деплой, платежи и поддержка множества провайдеров.
