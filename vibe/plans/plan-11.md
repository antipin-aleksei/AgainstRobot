# plan-11: Проверка iOS-проекта на облачном Mac

Статус: заблокирован — CI подготовлен, публикация и фактический облачный прогон
не подтверждены. Родитель: [roadmap-1](../roadmap/roadmap-1.md).

## Цель и место в очереди

Получить воспроизводимые результаты Debug/Release-сборки и UI smoke-тестов
на GitHub-hosted Mac. Это техническая предпосылка приёмки [plan-1](plan-1.md),
добавленная следующим свободным номером. Порядок продуктовых этапов остаётся
plan-1 → plan-2 → … → plan-10; plan-2 пока не начинать.

## Зависимости и границы

Нужны подготовленный каркас plan-1, право пользователя на публикацию репозитория
и доступ к GitHub Actions. Пользователь запросил публичный репозиторий и запуск
CI. macOS job выполняется только при `github.event.repository.private == false`,
на стандартном `macos-15`. Приватный macOS runner, larger runners, платные
сервисы, signing и развёртывание не входят в объём.

## Реализация

1. Опубликовать репозиторий с уже полученным разрешением пользователя и проверить
   фактическую видимость до запуска macOS.
2. Добавить workflow на push `main`, pull request и `workflow_dispatch`, с
   `contents: read`, закреплёнными SHA actions, отменой устаревших прогонов и
   лимитом 30 минут.
3. Выбрать Xcode 16.4 из образа `macos-15`; записать реальные версии. Через
   `simctl` JSON выбрать доступный iPhone/runtime того же поколения, что и SDK,
   дождаться готовности загрузки.
4. Выполнить unsigned Debug `build-for-testing`, существующие UI smoke-тесты
   `test-without-building` и unsigned Release `build`. Проверить ненулевое число
   завершённых успешных тестов и отсутствие ошибок; сохранить exit codes.
5. Сохранять логи, destination, JSON summary и `.xcresult` при любом исходе
   на 7 дней. При ошибке исправить причину и повторить соответствующий прогон.
6. Записать URL запуска, проверенный commit SHA, Xcode/SDK/macOS, destination,
   команды, число тестов и результаты сборок. Передать независимому ревью.

## Критерии готовности

Публичная видимость проверена. Реальный workflow завершился успешно на том же
commit SHA, который принимается: Debug и Release собраны, UI-тесты выполнены
с числом успешных тестов больше нуля, диагностика доступна. Результат и
ограничения отражены здесь, в README и plan-1. Наличие YAML, статическая проверка,
пропущенный job и ноль тестов не являются выполнением.

## Текущий отчёт

Workflow и инструкции подготовлены. Официальный список ПО `macos-15` проверен:
он содержит `/Applications/Xcode_16.4.app`, iOS Simulator SDK 18.5 и runtimes
iOS 18.5/18.6. Выбор доступного устройства выполняется на каждом runner заново.
SHA checkout v6 и upload-artifact v6 сверены с официальными Git refs.

В Linux actionlint 1.7.12 проверил workflow без замечаний. Это статическая
проверка конфигурации; Xcode и Simulator в этой среде отсутствуют. Реальный
облачный запуск ещё не подтверждён, URL и число выполненных тестов отсутствуют.
До получения доказательств plan-11 и plan-1 остаются заблокированы.

Независимое ревью конфигурации и документации для коммита `9638711` выполнено
отдельным агентом: замечаний к коду CI не найдено. Это не подтверждает публичную
видимость или выполнение workflow. Доступ к `api.github.com` блокируется прокси
облачного окружения; адрес добавлен в черновик сетевых настроек для сохранения
и публикации пользователем. До применения настроек изменение видимости и
управление прогонами через API недоступны.
