# plan-11: Проверка iOS-проекта на облачном Mac

Статус: выполнен — публичная видимость, Debug/Release и 2 UI-теста подтверждены. Родитель: [roadmap-1](../roadmap/roadmap-1.md).

## Цель и место в очереди

Получить воспроизводимые результаты Debug/Release-сборки и UI smoke-тестов
на GitHub-hosted Mac. Это техническая предпосылка приёмки [plan-1](plan-1.md),
добавленная следующим свободным номером. Порядок продуктовых этапов остаётся
plan-1 → plan-2 → … → plan-10; технический блокер plan-1 снят.

## Зависимости и границы

Нужны подготовленный каркас plan-1, право пользователя на публикацию репозитория
и доступ к GitHub Actions. Пользователь запросил публичный репозиторий и запуск
CI. macOS job выполняется только при `github.event.repository.private == false`,
на стандартном `macos-15-intel`. Приватный macOS runner, larger runners, платные
сервисы, signing и развёртывание не входят в объём.

## Реализация

1. Опубликовать репозиторий с уже полученным разрешением пользователя и проверить
   фактическую видимость до запуска macOS.
2. Добавить workflow на push `main`, pull request и `workflow_dispatch`, с
   `contents: read`, закреплёнными SHA actions, отменой устаревших прогонов и
   лимитом 30 минут.
3. Выбрать Xcode 16.4 из образа `macos-15-intel`; записать реальные версии. Через
   `simctl` JSON выбрать доступный iPhone/runtime того же поколения, что и SDK,
   дождаться готовности загрузки.
4. Выполнить unsigned Debug `build-for-testing`, существующие UI smoke-тесты
   `test-without-building` и unsigned Release `build`. Проверить ненулевое число
   завершённых успешных тестов и отсутствие ошибок; сохранить exit codes.
5. Сохранять логи, destination, JSON summary и `.xcresult` при любом исходе
   на 7 дней. При ошибке исправить причину и повторить соответствующий прогон.
6. Записать URL запуска, проверенный commit SHA, Xcode/SDK/macOS, destination,
   команды, число тестов и результаты сборок. Передать независимому ревью.

## Критерии готовности

Публичная видимость проверена. Реальный workflow завершился успешно на том же
commit SHA, который принимается: Debug и Release собраны, UI-тесты выполнены
с числом успешных тестов больше нуля, диагностика доступна. Результат и
ограничения отражены здесь, в README и plan-1. Наличие YAML, статическая проверка,
пропущенный job и ноль тестов не являются выполнением.

### Выбор Intel runner — 2026-10-27

После пяти минут в очереди ARM и сообщения GitHub о нехватке доступных
macOS arm64 runner выбран стандартный публичный `macos-15-intel`.
[Официальная таблица GitHub](https://github.com/github/docs/blob/main/data/reusables/actions/supported-github-runners.md)
указывает эту метку для Intel; `macos-15` теперь соответствует arm64.
[Список ПО Intel-образа](https://github.com/actions/runner-images/blob/main/images/macos/macos-15-Readme.md)
подтверждает Xcode 16.4 по прежнему пути и iOS Simulator SDK 18.5.
Оба источника проверены 2026-10-27. Условие публичной видимости, выбор доступного
симулятора, сборки и все UI-тесты сохранены. Метка снижает зависимость от
очереди ARM, но не гарантирует доступность Intel или успешное выполнение.
Реальный прогон на Intel ещё не подтверждён; блокеры приёмки остаются.
После смены метки `/tmp/againstrobot-actionlint/actionlint -color
.github/workflows/ios-ci.yml` (1.7.12) завершился с кодом 0 без замечаний;
`git diff --check` также завершился с кодом 0. Это статические проверки.

## Успешная облачная проверка — 2026-10-27

[Run 40526374430](https://github.com/antipin-aleksei/AgainstRobot/actions/runs/40526374430) завершился `success`.

ручной запуск выполнен с временной ветки `ci/validate-intel` из-за задержки
отмены старого ARM-прогона в concurrency-группе main.

- Стандартный `macos-15-intel`, macOS 15.7.9 (24G830).
- Xcode 16.4 (16F6), Apple Swift 6.1.2, Simulator SDK iOS 18.5.

- Debug `build-for-testing`: успешно.
- `test-without-building`: **2 теста, 0 ошибок**, оба XCTest выполнены.
- `xcresulttool` summary: **2 passed, 0 failed**.
- Release `build`: успешно.
- Загрузка артефакта `ios-diagnostics-40526374430-1`: успешно.

Логи прочитаны через GitHub API; проверены реальные строки `TEST BUILD SUCCEEDED`,
`TEST EXECUTE SUCCEEDED`, `UI tests: 2 passed, 0 failed`, `BUILD SUCCEEDED`.
Полные команды находятся в workflow и README; exit status команд сохранён
через `set -euo pipefail`.

Причина первого падения установлена по AX-дереву и координатам события:
XCTest нажимал центр строки-обёртки Toggle. Исправление `6d5123e` направляет
нажатие на вложенный Switch и сохраняет все проверки состояния и текста.
Независимое ревью исправления и выбора Intel runner не нашло замечаний.

Симуляторный запуск, главная, переходы на четыре экрана и обратно, безопасное
значение mock-режима и обе смены состояния подтверждены UI-тестами. Ручная
оценка интерфейса человеком, физический iPhone и голос не проверялись и не
входят в результат этого CI. Подпись, TestFlight и App Store не выполнялись.

Доступ к логам и исходному артефакту восстановлен. Хост Azure для нового
артефакта отличается (`productionresultssa8.blob.core.windows.net`) и пока
блокируется прокси этой среды. Это ограничивает скачивание именно нового
пакета агентом, но не выполненные тесты: логи доступны, артефакт загружен
и доступен пользователю в Actions. При необходимости добавить новый хост
в настройки; разрешения на остальные хосты не менять.
