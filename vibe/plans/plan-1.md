## Шаги реализации

1. Проверить доступность macOS и Xcode. Выбрать поддерживаемую минимальную версию iOS и зафиксировать версии инструментов. Если работа идёт на Linux, подготовить проект воспроизводимым способом и явно оставить сборку на Mac непроверенной.
2. Создать iOS-приложение SwiftUI. Разделить код на App, Features, Models и Services без лишних модулей и внешних зависимостей.
3. Добавить корневую навигацию и пустые экраны главной, персонажа, завязки, игры и карточки героя.
4. Добавить переключаемый режим тестовых данных, исключающий обращения к платным API.
5. Описать в README открытие проекта, сборку и запуск. Настроить .gitignore для Xcode и локальных секретов.

## Критерии готовности и проверки

Проект собирается на Mac; приложение открывает главную на симуляторе. Зафиксированы точная команда сборки и её результат.

Запускать содержательные проверки для изменённого поведения. Указать команды, среду и фактический результат; нулевое число тестов и проверка исходников не заменяют сборку и запуск. Если нет Mac, устройства или ключа, выполнить независимую часть и явно указать блокер: план целиком не закрывать.

## Отчёт реализации

Подготовлен каркас SwiftUI: App, Features, Models, Services; главная и четыре
пустых экрана доступны через NavigationStack. Добавлен переключатель тестового
режима (включён по умолчанию); оба положения офлайн, сервис не подключён.
Игровых данных и поведения plan-2 пока нет.

В Git включены Xcode-проект, общая схема и два UI smoke-теста. Выбраны iOS 17.0,
Xcode 16.0 / macOS 14.5+ / SDK iOS 18.0, языковой режим Swift 5.0. Это целевая
конфигурация, не подтверждённая сборкой. Инструкции, команды и требования —
в [README](../../README.md); постоянные правила — в [SUPERPOWERS](../SUPERPOWERS.md).

Проверка в Linux x86_64 / Python 3.12.14: OpenStep-парсер читает проект;
структурные проверки ссылок, включения исходников, схемы и JSON ресурсов
выполнены отдельно от сборки. `xcodebuild ... test CODE_SIGNING_ALLOWED=NO`
завершился кодом 127: `xcodebuild: command not found`. UI-тесты не запущены;
RED/GREEN не подтверждён. Сборка и запуск приложения не проверены.

На Mac выполнить полные команды `build` и `test` из README, вручную проверить
главную и возврат с четырёх экранов, записать фактические версии и результат.
До этого статус «выполнен» не ставить, plan-2 не начинать. Независимое ревью
спецификации и качества выполнено отдельным агентом для коммита `6de5457`.
Конкретных статических дефектов кода, Xcode-проекта и схемы не выявлено.
Приёмка остаётся заблокирована: требуется реальная сборка и запуск на Mac.
Ревью не заменяет проверку компиляции и поведения приложения.

Добавлен workflow iOS CI: Xcode 16.4 на `macos-15-intel`, доступный iPhone runtime,
Debug build-for-testing, UI test-without-building с проверкой ненулевого числа
успешных тестов, Release build и артефакты диагностики. Job запускается только
при публичной видимости репозитория. Конфигурация проверена статически в Linux;
URL реального запуска, результаты Xcode и тестов пока отсутствуют. Это не
закрывает plan-1. Публикация и первый прогон вынесены в [plan-11](plan-11.md).
